## 0. 一句话定义

**教师赋能智能平台** —— 一个面向**班主任**的、无日常人工干预的「AI 赋能助手 + 自主装备中心」：教师用自然语言描述遇到的任何工作难题（自己的状态 / 班级的问题 / 学生的困扰 / 家长的冲突 / 学习的困难），平台的**统一智能体引擎**自动理解问题归属、分流到对应模块、完成评估分型、匹配可执行的方案与工具，并持续追踪效果。全程无人介入；仅在触及安全红线时，启动不可绕过的"熔断—心理专员"通道。

## 1. 为什么做这个产品（Problem & Why Now）

### 1.1 教师的现实困境

| 困境 | 表现 | 数据来源 |
|---|---|---|
| **职业倦怠高发** | 66.6% 存在不同程度倦怠 | 技术理论手册 |
| **班主任风险倍增** | 是非班主任的 2.3 倍 | 理论手册 |
| **第一压力源是家长** | 家长沟通压力超过学业和时长 | 业务手册 |
| **共情疲劳普遍** | 96.71% 存在不同程度共情疲劳 | 理论手册 |
| **不愿当班主任** | 70%+ 不愿或犹豫 | 业务手册 |

### 1.2 现有支持方式的缺口

| 缺口 | 说明 |
|---|---|
| **零散** | 心理支持、班级管理、家校沟通、学生个案、学习诊断——各是一套独立体系，教师遇到问题时不知道找谁 |
| **被动** | "出了问题再找人谈话"，缺乏日常预防和早期干预 |
| **人力瓶颈** | 依赖少数顾问/心理教师的经验判断，无法规模化覆盖 |
| **理论深、落地浅** | 各领域有成熟的理论框架（依恋理论、五系统模型、双维家长分类等），但教师拿到的是厚厚的培训材料，不是"今天就能用的工具" |

### 1.3 本产品的核心假设

> **如果能把五大领域的心理学理论与方法论，编码成一个"听得懂教师语言、能判断问题归属、能给出可执行方案、还能追踪效果"的智能体引擎——那么教师就拥有了一个 24 小时在线、零负担、个性化的赋能助手。**

这个假设成立的前提：
1. 教师愿意用自然语言描述自己遇到的真实问题
2. 引擎能准确识别问题属于哪个模块、什么级别
3. 匹配出的"装备"（话术/工具卡/SOP/微行动）确实能帮助教师在当下场景中行动起来
4. 追踪闭环让教师感受到"有用"，从而形成使用习惯

### 1.4 不做的代价

- 教师持续耗竭 → 离职率上升、班级氛围恶化
- 问题积压到爆发才被看到 → 处理成本指数级上升
- 新手班主任没有"抓手" → 靠试错成长，周期长、代价大

## 2. 目标（Goals）

### 2.1 用户目标（教师得到什么）

| # | 目标 | 可衡量 |
|---|---|---|
| U1 | **一个问题入口**：不管遇到什么类型的难题，都能在一个地方说清楚并获得帮助 | 首次找到正确模块的路径 ≤2 次点击 |
| U2 | **说人话就行**：用自然语言描述问题，不用背专业术语也不需要先判断"这算哪类问题" | 自然语言→模块分流准确率 ≥85% |
| U3 | **给方案也给工具**：不只是分析，还给我"明天就能用的话术/步骤/模板" | 方案中含可执行工具的比例 =100% |
| U4 | **我的数据只有我能看**：不管是自己的状态还是学生/家长的个案，都绝对私密 | 数据合规事件 =0；匿名自评可信度 ≥85% |
| U5 | **零负担**：单次使用 ≤10 分钟（轻度问题）；重度问题也分段进行，不要求一次填完 | 单次会话完率 ≥70% |
| U6 | **真有危险时有人接**：危机情况不装没事，立刻给我求助指引并通知专业人员 | 危机转介及时率 =100% |

### 2.2 业务目标（平台方得到什么）

| # | 目标 | 可衡量 |
|---|---|---|
| B1 | **规模化覆盖**：不增加人力编制即可服务全校班主任 | 单校支撑 ≥200 名教师，无需新增顾问工时 |
| B2 | **早期发现**：教师状态问题和学生高危信号在早期就被识别 | 预警信号提前量 ≥4 周（vs 传统被动模式） |
| B3 | **效果累积**：教师使用后状态改善、问题解决率提升 | 3 个月教师自评改善率 ≥40%；个案 SOP 完成率 ≥60% |

### 2.3 效果诚实原则

> 手册明确承认"轻量工具短期效果不显著，需时间累积"。B3 取 3 个月为观测周期，不做"一周见效"承诺。对外沟通须匹配此节奏。

## 3. Non-Goals（明确不做什么）

| # | 不做什么 | 理由 |
|---|---|---|
| NG1 | ❌ 不做精神障碍诊断 / 治疗（对教师、学生、家长均同） | 非医疗产品；筛查 ≠ 诊断 |
| NG2 | ❌ 不替代心理咨询师 / 医生 / 法律等专业介入 | 红线场景一律转介 |
| NG3 | ❌ 不做教师绩效考核 / 管理评价用途 | 否则教师不敢诚实填写，引擎失效 |
| NG4 | ❌ 不设校领导 / 管理层数据视角（含匿名聚合看板） | 已确认不考虑该群体 |
| NG5 | ❌ 不独立处理任一模块的危机 | 必须熔断转介心理专员 |
| NG6 | ❌ 不向学生 / 家长开放平台账号 | 学生和家长是数据客体，非用户 |
| NG7 | ❌ 不承诺短期显著效果 | 效果累积需时，避免夸大 |
| NG8 | ❌ 不对低依恋安全感教师使用激活恐惧语义 | 依恋知情硬约束 |
| NG9 | ❌ 不把学生/家长个案数据暴露给任何非授权角色 | 学生/家长数据仅录入教师可见 + 红线个案路由心理专员 |

## 4. 用户与角色

| 角色 | 定义 | 权限范围 |
|---|---|---|
| **班主任（唯一终端用户）** | 平台唯一使用者 | 描述问题、完成评估/录入、查看自己的所有数据和档案、接收并执行方案、标记完成/反馈、触发/接收危机转介信息 |
| **统一智能体引擎（系统核心）** | AI 驱动的自动化决策与服务层 | 自然语言理解 → 模块分流 → 评估采集 → 分级分型 → 方案生成 → 工具匹配 → 推送 → 追踪 → 升降级 → 安全红线监测 |
| **心理专员（唯一人类触点）** | 校方指定 | **仅在两类场景出现**：①任一模块的安全红线熔断时接收转介包；②橙/红级降级时做一次性"确认不干预"复核。无日常数据查看权，无干预制定权 |
| ~~顾问端 / 管理层端~~ | —— | **本期不做**，已废弃 |

### 边界精确化

"无人工干预"指**日常赋能闭环 100% 由引擎驱动**。唯一的两处人类触点（危机转介 + 橙红降级复核）是法律/伦理的逃逸通道与最小必要妥协，不属于"日常运营干预"。

## 5. 五大模块——帮教师解决什么问题

> 本章是整个产品的"灵魂"。每模块回答三个问题：① 教师在这个领域会遇到什么典型难题？② 我们用什么理论框架去理解这些难题？③ 我们给教师什么样的"装备"来解决？

### 5.1 模块一：班主任自我成长赋能

**教师遇到的典型难题**：
- 总觉得"做得不够好"，下班了还在想班上的事
- 和家长沟通后情绪久久不能平复
- 对某个学生投入很多但看不到改变，感到挫败和无力
- 不知道自己是"累"还是"倦怠"，不敢跟别人说
- 同事都说"当老师就这样"，但自己真的很难受

**背后的理论框架**：
- **压力三角**：外源压力（家长/行政/工作量）× 认知扭曲（完美主义/全能感）× 内源脆弱（低自我效能/低意义感）三者的叠加
- **双重依恋困境**：教师既需要与学生/家长建立依恋关系（这是工作的情感基础），又需要在关系结束后能够健康分离（避免耗竭）
- **五类互动模式**：A 型（过度负责）、B 型（控制导向）、C 型（回避伪装）、D 型（混乱摇摆）、E 型（疏离退缩）——每种模式有不同的脆弱点和优势资源
- **六色预警体系**：绿/蓝/黄/橙/红/紫六级状态，对应不同响应强度

**我们给的"装备"**：
| 装备类型 | 示例 | 使用场景 |
|---|---|---|
| 3 分钟补能法 | 呼吸锚定 / 正念着陆 / 身体扫描 | 感觉"快炸了"的时候立刻用 |
| 认知转换卡 | "我不是'应该做好'，我是'在做一件有意义的事'" | 完美主义发作时 |
| 边界话术模板 | "我理解您的焦虑，但我现在需要先处理……" | 家长越界时 |
| 影响力日志 | 每天记一件"我做对了的小事" | 感觉"做什么都没用时" |
| 压力分解表 | 把"一大堆烦心事"拆成"能控制的 / 不能控制的" | 被压得喘不过气时 |

**什么时候需要特别小心（红线）**：
- 教师表达自伤/自杀想法 → 立即转介
- 依恋安全感极低（AS≤5）→ 强制温柔模式，禁止任何激活恐惧的内容
- 意义感连续 4 周极低（紫色预警）→ 主动关爱 + 转介评估

### 5.2 模块二：班级系统建设

**教师遇到的典型难题**：
- 接了一个"乱班"，不知道从哪里入手
- 班规定了但不执行，成了墙上的装饰
- 班干部选了但不管用，什么事都还是自己扛
- 班级氛围要么太松（管不住）要么太紧（死气沉沉）
- 到了学期中，开学时的劲头全没了

**背后的理论框架**：
- **四阶生长模型**：生存期（建立秩序）→ 规范期（形成习惯）→ 运行期（自主运转）→ 成熟期（文化引领）——每个阶段有不同的建设重点和成功标志
- **五系统诊断**：目标/组织/活动/环境/关系五个子系统，哪个弱补哪个
- **班级能量场**：班级作为一个系统的整体"气场"——积极/消极/混乱/僵化的不同场域特征

**我们给的"装备"**：
| 装备类型 | 示例 | 使用场景 |
|---|---|---|
| 班委组建六步法 | 从岗位设计到选举到培训的全流程 | 接新班第一周 |
| 班级公约六步法 | 全员参与制定→签字→公示→执行→复盘 | 班级没规矩时 |
| 一日 SOP 模板 | 早读到放学的关键节点清单 | 班级秩序混乱时 |
| 危机处置六步法 | 冲突发生后的标准应对流程 | 班里出了突发状况 |
| 五系统速评卡 | 15 题 5 分钟自评，定位短板 | 不知道问题在哪时 |
| 教师情绪 5 步法 | 在班级事务中被激怒时的自我调节 | 快要在班里爆发时 |

**什么时候需要特别小心（红线）**：
- 发现班级内有学生存在自伤工具或有严重冲突事件 → 立即上报 + 心理转介
- 班级整体呈现 A/B 级危机征兆 → 不允许教师独自处置

### 5.3 模块三：家校沟通与合作

**教师遇到的典型难题**：
- 有的家长完全不配合，消息不回、会议不来
- 有的家长过度干涉，对教学方式指手画脚
- 被家长投诉了，感到委屈又不知道怎么回应
- 家长群里一句话引发误解，越解释越乱
- 明明是为了孩子好，但感觉和家长总是"不在一个频道"

**背后的理论框架**：
- **双维家长分类**：配合度维度（P1–P5）× 态度维度（A–E），25 种组合决定了不同的沟通策略
- **九级容器模型**：教师与家长之间的"关系容器"有多大，决定了能承载多大张力的对话
- **三层嵌套**：具体问题 → 关系模式 → 依恋底色——沟通问题往往不是"技巧"问题，而是更深层的信任问题

**我们给的"装备"**：
| 装备类型 | 示例 | 使用场景 |
|---|---|---|
| 双维评定六步法 | 快速给家长"定位"，匹配对应策略 | 遇到一个"难搞"的家长时 |
| 73855 沟通法则 | 先听懂再说的标准化流程 | 每次正式沟通前 |
| 先跟后带话术 | 先认同感受再引导方向的句式模板 | 家长情绪激动时 |
| EQ 四步法 | 情绪→需求→边界→方案的沟通框架 | 需要和家长达成一致时 |
| 分场景 SOP | 家长会/投诉处理/群消息/家访等场景的标准流程 | 特定沟通场景 |
| E 级管控台 | 面对威胁性家长的自我保护和上报流程 | 被家长威胁/恶意维权时 |

**什么时候需要特别小心（红线）**：
- 家长出现 E 级行为（公开抹黑/威胁恐吓/恶意维权）→ 推送保护 SOP + 通知心理专员/德育，AI 不替代面谈

### 5.4 模块四：学生个体问题

**教师遇到的典型难题**：
- 班上有个孩子"就是不服管"，试了很多方法都没用
- 有学生突然变得不爱说话、成绩下滑、不合群
- 学生之间起了冲突，两边家长都要说法
- 担心某个学生可能有更深层的问题（家庭因素？心理因素？），但不知道怎么判断
- 自己的情绪被某个学生的问题"勾住了"，处理时不够客观

**背后的理论框架**：
- **五类十五型**：将学生行为问题分为学业/行为/情绪/社交/适应五大类，每类下 2–4 种亚型
- **三重叠加**：个体发展 × 家庭系统 × 学校生态——学生的问题往往是多层因素的叠加
- **L1–L3 响应分级**：L1 教师自主处理 → L2 年级协同 → L3 专业会商——根据问题的复杂度匹配响应层级
- **依恋心智化**：理解学生的"问题行为"背后可能是依恋需求未满足的表现

**我们给的"装备"**：
| 装备类型 | 示例 | 使用场景 |
|---|---|---|
| 问题快速编码 | 用简单描述 → 自动归入某类某型 | 刚发现一个学生有问题时 |
| 12 项 SOP 工具库 | 定时器/行为契约/情绪命名/友谊桥/T12 心智化等 | 不同问题类型对应不同 SOP |
| 依恋增强版操作 | 在常规干预基础上加入依恋敏感调整 | 对有明显依恋损伤迹象的学生 |
| 个案记录模板 | 结构化记录学生问题、干预过程、变化轨迹 | 需要跟踪一个学生时 |
| 教师自我觉察检查 | 处理学生问题前先检视自己的情绪状态 | 感到自己"被勾住"时 |

**什么时候需要特别小心（红线）**：
- 发现体罚/虐待/自伤迹象（E2）→ 1h 内上报
- 学生危机三级：黄（关注）/橙（4h 内响应）/红（0 延迟，立即行动）
- 所有红线一律不走"教师自主处理"

### 5.5 模块五：学生学习问题

**教师遇到的典型难题**：
- 学生"不想学""学不会""学了没用"——三种完全不同的问题却容易被混为一谈
- 家长只看分数，不理解孩子的真实困难在哪里
- 试了很多方法（补习、谈心、奖励），但效果不明显
- 不确定某个学生的学习问题是"态度问题"还是"能力问题"还是"心理问题"
- 自己的教学方法和学生的学习特点不匹配，但不知道怎么调

**背后的理论框架**：
- **1+3+1 教学**：1 个目标 + 3 层支架（近端/中端/远端）+ 1 个评估循环
- **六力心理学框架**：从心理学角度理解学习困难的六大动力因素
- **HERO 模型**：希望/效能/抗逆/乐观——影响学习的心理资本四维
- **三层诊断**：行为层 / 认知层 / 关系层——学习问题往往不只发生在"行为"表面

**我们给的"装备"**：
| 装备类型 | 示例 | 使用场景 |
|---|---|---|
| 三层诊断工具 | 行为/认知/关系三维评估 | 遇到"搞不定"的学习困难学生时 |
| 五步诊疗法 | 识别→归因→目标→干预→追踪的标准化流程 | 系统性地帮助学生 |
| 25 项工具库 | ZPD 支架/目标拆解/元认知训练/动机激发等 | 不同诊断结果匹配不同工具 |
| 黄金话术卡 | 和学生/家长谈学习的句式模板 | 需要沟通学习问题时 |
| 分学段策略表 | 低/中/高年级的学习问题差异化策略 | 不同年级的学生 |

**什么时候需要特别小心（红线）**：
- 学生表达自杀言语 / 自伤行为 / 暴力倾向 / 重大创伤史 / 严重躯体化症状 → 任一命中即走危机流程

### 6.2 两种入口路径（来自思维导图）

#### 路径 A：AI 智能入口（推荐默认路径）

**适用场景**：教师不确定自己的问题属于哪个模块，希望"我说你帮我判断"

```
教师打开平台 → 点击「AI 智能助手」→ 用自然语言描述遇到的问题
→ AI 多轮动态追问（澄清细节/排除歧义/确认紧急程度）
→ 交互式展析（给出"XX模块 XX% 可能性, YY模块 YY% 可能性"）
→ 教师确认主要/次要问题归属
→ 进入对应模块的处理流程
```

**示例对话**：
> 教师："最近班上有个孩子老是不交作业，跟他谈了好几次没用，他爸妈也不管，我很头疼"
>
> AI 追问 1："这个问题让您最困扰的是什么？A. 学生成绩受影响 B. 家长不配合 C. 您觉得自己方法不对 D. 其他"
>
> 教师："主要是家长不配合，每次沟通都很费劲"
>
> AI 追问 2："您提到家长沟通比较困难，那学生本人的学习态度怎么样？是完全不想学，还是有困难但愿意尝试？"
>
> 教师："其实孩子是想学的，就是家里没人管"
>
> AI 展析：「基于您的描述，这个问题涉及两个层面：
> - 📌 主要（70%）：家校沟通与合作 —— 家长配合度低 + 沟通效率不高
> - 📌 次要（30%）：学生学习问题 —— 家庭支持缺失导致的外部阻碍
> 建议我们先从家校沟通切入，同时在学习问题上给您一些针对"家庭支持不足"的工具。
> 您同意这个方向吗？」
>
> 教师："同意"
>
> → 进入模块三（家校沟通）的处理流程，同时携带模块五（学习问题）的关联建议

#### 路径 B：模块快捷入口

**适用场景**：教师已经知道自己要处理什么类型的问题

```
教师打开平台 → 从首页直接选择模块图标
→ 进入该模块的专用流程（自然语言描述 + 模块专属评估/录入）
→ 模块引擎处理（评估打分 + 量表补充 + 系统综合分析）
→ 生成解决方案 + 配套工具
→ 教师查看方案 → 使用工具 → 反馈效果
```

## 8. 核心功能详细需求（按优先级）

> 验收标准采用 Given/When/Then 格式。P0=不交付则核心闭环不成立；P1=显著改善体验；P2=远期增强。

### 8.1 【P0】统一智能体入口（AI Gateway）

**功能描述**：平台首页的核心交互界面。教师用自然语言描述问题，AI 通过多轮追问澄清后给出模块归属判断（含置信度百分比），经教师确认后分流到对应模块。

**关键能力**：
1. **自然语言理解**：能理解教师的口语化描述（不必用专业术语）
2. **多轮动态追问**：根据已有信息判断还需要澄清什么（排除歧义/确认紧急程度/区分主次问题）
3. **交互式展析**：以"模块名 + 置信度百分比"的形式展示判断结果，支持主/次问题标注
4. **紧急检测**：在追问过程中一旦检测到危机关键词（自伤/暴力/虐待等），立即中断正常流程，转入熔断通道

**验收标准**：
- Given 教师输入一段自然语言问题描述，**When** AI 处理完毕，**Then** 输出至少 1 个模块归属建议 + 置信度百分比，且允许教师确认或修正。
- Given 教师描述中包含危机信号，**When** AI 检测到，**Then** 在 <10 秒内中断正常分流，展示求助指引 + 触发熔断。
- Given AI 给出模块归属判断，**When** 教师点击"确认"，**Then** 无缝跳转到对应模块的处理流程，且携带上下文（教师原始描述 + 追问记录）。
- Given 单次对话，**When** 教师完成从输入到确认分流，**Then** 全程 ≤3 分钟（不含后续模块处理时间）。

### 8.2 【P0】五大模块独立处理引擎

每个模块在收到分流（或从模块快捷入口直接进入）后，执行以下流程。以**模块一（自我成长）**为例详述，其余模块遵循同一模式但配置不同。

#### 8.2.1 模块一：自我成长 — 详细流程

```
进入模块 → 自然语言描述当前状态（可选，也可跳过直接做评估）
→ 快速路线 / 深度路线 选择
  ├─ 快速路线：五问自评（5题，3分钟）→ 六色预警计算 → 匹配微行动 → 完成
  └─ 深度路线：五问 → HERO(12题) + AS(3题) + PCS(5题) → 六维深度评估(46题)
     → T型画像 + 互动模式 + 归因分析
     → 六维赋能方案（心理/技能/关系/意义/系统/数字 组合）
     → 微行动推送 + 工具卡 + 日志模板
```

**六色预警硬规则（引擎内置，不可修改）**：

| 条件 | 等级 | 含义 |
|---|---|---|
| 五问总分 ≤10 且各项 ≤2 | 🟢 绿色 | 状态良好，维持节奏 |
| 总分 11–14，无单项 ≥3 | 🔵 蓝色 | 轻微波动，关注即可 |
| 总分 15–19 或任一单项 ≥3 | 🟡 黄色 | 需要支持，启动推送 |
| 总分 ≥20 或任何单项 ≥4 | 🟠 橙色 | 需要主动支持响应 |
| Q1 与 Q3 同时高分，或出现自伤/自杀表达 | 🔴 红色 | 立即 crisis 响应 |
| Q3 连续 4 周 ≤2 | 🟣 紫色 | 意义感持续低落，需深度关注 |

**依恋知情禁忌（硬约束，代码层强制过滤）**：

| 条件 | 禁止输出 |
|---|---|
| 教师互动模式 = A 型（过度负责） | "少付出 / 别那么负责 / 你做得太多了" 类语义 |
| 教师互动模式 = C 型（回避伪装） | 拆穿其"我没事"的防御 |
| 教师互动模式 = E 型（疏离退缩） | 强推其立即采取行动 / 大幅改变 |
| AS ≤5 | 任何激活恐惧语义；强制"先回应情感，后轻建议"模板 |

**验收标准**：
- Given 教师完成五问提交，**When** 引擎计算，**Then** <5 秒内输出六色等级，规则与上表 100% 一致。
- Given 教师画像为 A 型 + 当前 🟠，**When** 引擎生成建议，**Then** 候选中含"少付出"语义的工具被过滤（单元测试覆盖）。
- Given 教师选择深度路线，**When** 完成全套评估，**Then** 输出包含 T 型标签 + 互动模式 + 归因类型 + 六维加权方案。

#### 8.2.2 模块二：班级系统建设 — 流程概要

```
进入模块 → 判断问题场景
├─ 场景A：接手新班级（系统建设从头开始）
│   → 班级基础信息录入（如尚未录入）
│   → 五系统速评（15题，5分钟）→ 定位短板系统
│   → 四阶判定（当前处于哪一阶段）
│   → 能量场快评
│   → 生成建设处方：阶段策略 + 短板系统强化 + 教师自我建设工具
│
├─ 场景B：学期初规划（新学期开始）
│   → 学期规划引导（目标/里程碑/关键节点）
│   → 上学期复盘（如有历史数据）
│   → 生成学期计划模板 + 五系统维护建议
│
└─ 场景C：中途出现问题（运行中出现状况）
    → 问题领域判断（目标/组织/活动/环境/关系）
    → 相关系统深度评估
    → 症状识别（能量场偏移/规范失效/关系紧张等）
    → 问题定位 + 综合诊断 + 建设处方
    → 含危机响应预案（如涉及学生安全问题）
```

**验收标准**：
- Given 教师完成五系统速评，**When** 引擎分析，**Then** 输出各系统得分 + 短板标识 + 对应的建设工具推荐。
- Given 教师选择"接手新班级"场景，**When** 流程完成，**Then** 输出包含四阶段判定 + 能量场评级 + 至少 3 项可执行的行动建议。

#### 8.2.3 模块三：家校沟通与合作 — 流程概要

```
进入模块 → 自然语言描述沟通困境（对象/场景/发生了什么）
→ 双维家长评定（配合度 P1-P5 × 态度 A-E）
→ 容器速查（当前关系容器能承受多大张力）
→ 沟通记录（如有历史数据，自动关联）
→ 生成沟通方案：
   - 话术组合（根据双维匹配最佳话术库条目）
   - SOP 推荐（匹配具体场景）
   - E 级预警（如家长为 E 型，附加保护预案）
→ 教师执行沟通 → 反馈效果 → 更新容器评级
```

**验收标准**：
- Given 教师描述一位家长的沟通问题，**When** 引擎完成双维评定，**Then** 输出 P×A 坐标定位 + 对应话术推荐 + 容器评级。
- Given 评定结果为 E 型家长，**When** 生成方案，**Then** 必须包含 E 级管控 SOP + 心理专员通知提示。

#### 8.2.4 模块四：学生个体问题 — 流程概要

```
进入模块 → 选择/搜索学生（从"我的学生"列表中选择，或新增）
→ 自然语言描述学生问题（行为表现/持续时间/影响因素）
→ 问题快速编码（归入五类十五型之一）
→ L 级初步判定（L1教师自主 / L2年级协同 / L3专业会商）
→ 如 L1：生成 SOP 方案（12 项工具库中匹配）
       + 依恋增强版操作（如有依恋相关指标）
       + 教师自我觉察检查（防止反移情）
→ 如 L2/L3：提示升级路径 + 生成协同/会商准备材料
→ 个案记录存档 → 跟踪（S1-S5 进度标记）→ 复评
```

**验收标准**：
- Given 教师录入一个学生个案，**When** 引擎完成编码，**Then** 输出类别 + 亚型 + L 级判定 + 对应 SOP 推荐。
- Given L 级判定为 L3，**When** 生成方案，**Then** 包含会商准备材料模板 + 心理专员协同提示。

#### 8.2.5 模块五：学生学习问题 — 流程概要

```
进入模块 → 选择/搜索学生
→ 自然语言描述学习困难表现
→ 三层诊断引导：
   - 行为层：具体表现（作业/听课/考试/自主学习）
   - 认知层：理解力/注意力/记忆力/学习方法
   - 关系层：师生关系/同伴关系/家庭支持/亲子关系
→ HERO 心理资本快评（如涉及动力问题）
→ 诊断结论（一级轻/二级中/三级重 + 主导层次）
→ 五步诊疗法方案：
   1. 问题精确定义
   2. 多因素归因
   3. SMART 目标设定
   4. 干预措施（从 25 项工具库匹配）
   5. 追踪计划（每 4 周重评）
→ 黄金话术卡（用于和学生/家长沟通学习问题）
```

**验收标准**：
- Given 教师完成三层诊断，**When** 引擎分析，**Then** 输出主导问题层次 + 严重等级 + 对应干预工具组合。
- Given 诊断为三级重，**When** 生成方案，**Then** 包含转介建议 + 专业支持提示。

### 8.3 【P0】安全熔断通道（跨模块统一）

**功能描述**：所有模块共享同一套安全监测与熔断机制。任一模块的任一环节检测到红线信号，立即阻断当前流程，启动不可绕过的转介程序。

**统一红线汇总表**：

| 来源 | 红线信号 | 动作 |
|---|---|---|
| 任意模块 | 自伤/自杀相关表达 | 立即阻断 → 展示求助指引 → 转介包通知心理专员 |
| 自我成长 | AS≤5；Q1&Q3 同高；Q3 连续4周≤2 | 加强关注 + 通知心理专员 |
| 班级建设 | A/B 级危机（自伤工具清查/冲突超标） | 立即上报 + 心理转介 |
| 家校沟通 | E 级家长（抹黑/威胁/恶意维权） | E级管控SOP + 通知心理专员/德育 |
| 学生个体 | E2（体罚/虐待/自伤）；橙/红危机级 | 1h内上报 + 必要时110/120 |
| 学习问题 | 自杀言语/自伤/暴力/重大创伤/严重躯体化 | 标准危机流程 |

**验收标准**：
- Given 任一红线信号被检测到，**When** 熔断触发，**Then** <10 秒内阻断该模块常规输出，展示求助指引，生成转介工单通知心理专员。
- Given 转介触发，**When** 工单生成，**Then** 教师端常规推送暂停，状态标记"转介中"，所有操作留审计日志。
- **危机转介及时率 = 100%（不可妥协）**

### 8.4 【P0】信息管理中心

**功能描述**：教师个人数据的统一存储与视图。按"我的状态 / 我的班级 / 我的学生 / 我的家长 / 家校沟通档案 / 方案记录"六个区域组织。

**验收标准**：
- Given 教师登录，**When** 进入信息中心，**Then** 看到六个区域的入口，每个区域显示数据概览（如"3 名学生在跟踪中""本月 5 条沟通记录"）。
- Given 教师点击"我的学生"中的某学生，**When** 打开详情，**Then** 看到该学生的基本信息 + 个案记录时间线 + 关联的方案记录。
- Given 任意数据页面，**When** 渲染完成，**Then** 权限层保证不存在任何"分享给他人/管理员可见"的入口（NG9）。

### 8.5 【P1】追踪与反馈系统

**功能描述**：跨模块统一的追踪引擎。每个模块生成的方案/工具/微行动都被纳入追踪，记录：
- 是否执行
- 执行时间
- 效果反馈（教师自评有用/一般/没用 + 可选原因）
- 后续变化（学生行为变化/班级氛围变化/沟通改善等）

**追踪频率按模块差异化**：
- 自我成长：微行动每日/每周；五问每月；六色升降级按规则
- 班级建设：升阶条件按季度复盘；系统能量按月
- 家校沟通：容器评级按次更新；投诉降级率按月
- 学生个体：S1–S5 进度标记；L 级流转按规则
- 学习问题：每 4 周重评；效果按学期校准

**验收标准**：
- Given 教师完成一个方案中的某项工具执行，**When** 标记完成并打分，**Then** 追踪系统记录时间戳 + 评分 + 该工具在后续推荐中的权重调整（低分降权）。
- Given 教师查看"方案记录"，**When** 渲染列表，**Then** 每条方案显示状态（进行中/已完成/暂停）+ 效果摘要。

### 8.6 【P1】预警升降级系统

**功能描述**：基于追踪数据，各模块的预警/分级状态自动升降级。

**通用规则**：
- 连续 2 次正面评估/记录（间隔≥4周）→ 允许降一级
- 状态持续恶化（按各模块具体阈值）→ 自动升一级
- 任何红线信号 → 立即升至最高级 + 熔断

**降级确认规则**：
- 绿/蓝/黄级：引擎提议 + 教师自确认 → 自动生效
- 橙/红级：引擎提议 + **心理专员一次性复核**（仅确认不干预）→ 生效

**验收标准**：
- Given 符合降级条件且当前为🟡，**When** 教师确认，**Then** 等级下降，追踪频率降低。
- Given 符合降级条件且当前为🟠，**When** 引擎提议，**Then** 生成复核任务给心理专员，其一次性点击确认后生效；复核人无法修改方案或查看历史数据。

### 8.7 【P2】跨模块联动洞察（远期）

**功能描述**：在教师本人可见的前提下，展示模块间的联动洞察。例如：
- "您最近的家校沟通压力升高（模块三 🟡→🟠），这与您的自我成长外源压力得分升高（模块一）可能相关"
- "班级能量场偏低（模块二）+ 学生个体问题增多（模块四）→ 建议优先从班级系统建设入手"

**约束**：所有联动洞察仅使用聚合/趋势数据，**绝不泄露任何学生/家长/其他教师的个体信息**。

## 9. 用户故事（User Stories）

### P0（核心闭环）

- **US-01**：作为班主任，我希望用自然语言告诉平台"我今天遇到了什么问题"，而不需要先判断这算哪一类问题，以便平台帮我归类并给出方向。
- **US-02**：作为班主任，当我描述的问题涉及多个模块时（比如"家长不配合导致学生不交作业"），我希望平台能告诉我"主要是什么问题、次要涉及什么"，而不是只给一个答案。
- **US-03**：作为班主任，我希望平台给我的不只是分析，还有"明天就能用"的具体工具（话术/步骤/模板），而不是一堆理论。
- **US-04**：作为班主任，我希望我在平台上录入了关于某个学生的所有信息（问题/干预/变化），**只有我自己能看到**，以便我敢如实记录。
- **US-05**：作为班主任，当我在任何地方提到了自伤、自杀、虐待等内容时，我希望平台立刻给我求助指引并通知专业人士，而不是假装没看见继续给我推工具。

### P1（体验增强）

- **US-06**：作为班主任，我希望我在模块 A 里录入的数据（比如某个学生的问题），在模块 B 里也能被关联看到（比如在家校沟通模块里提到这个学生的家长），不需要重复录入。
- **US-07**：作为班主任，我希望我用了某个工具之后可以标记"有用/没用"并写一句原因，这样平台以后推的东西越来越准。
- **US-08**：作为班主任，如果我正在处理的事情很急（比如家长正在群里闹），我希望平台能给我一个"应急模式"——最快速度给我最关键的 1–2 条建议，而不是让我先做一轮评估。
- **US-09**：作为班主任，我希望能看到自己一段时间以来的"方案执行记录"——哪些做了、哪些没做、效果怎样，像一个工作台账。

### P2（远期）

- **US-10**：作为班主任，我希望平台能告诉我"您最近的状态变化可能和某某方面的压力有关"这种跨模块的洞察，帮助我看到自己没意识到的联系。
- **US-11**：作为班主任，如果我用自由文字描述了一个很复杂的情境，希望能得到比选择题更精准的分析（即使平台告诉我"我不太确定，仅供参考"）。

### 边界/异常故事

- **US-12**：作为班主任，如果我在填到一半的时候被叫走了，我希望下次进来能接着填，而不是从头开始。
- **作为班主任，如果我的依恋安全感很低**，我希望平台全程用温和的方式和我说话，不要出现任何刺激性的内容。（继承自主版 PRD US-13）
- **作为班主任，如果我已经连续多次忽略了平台的推送**，我希望平台降低频率而不是加大力度轰炸我。（继承自主版 PRD US-14）

## 11. 指标体系

### 11.1 北极星指标

| 指标 | 定义 | 目标 |
|---|---|---|
| **班主任月度主动活跃率** | 月内至少完成 1 次有效交互（评估/录入/工具使用）的教师数 / 应覆盖教师数 | **>70%** |

> 一切价值的前提。教师不活跃，引擎就没有数据，没有数据就没有准确的分型和匹配，没有匹配就没有有用的工具推送——整个链条断裂。

| 学生个体 | 个案 SOP 完成率；L1 自主解决率；L2/L3 及时升级率 | ≥60%；待定；100% |
| 学习问题 | 三层诊断覆盖率；五步法使用率；4 周重评执行率 | 待定；待定；≥80% |

| 指标 | 目标 |

## 14. 风险与缓解

| 风险 | 说明 | 缓解 |
|---|---|---|
| **AI 分流不准** | 教师的自然语言描述模糊，导致分错模块 | 多轮追问澄清 + 置信度展示 + 教师最终确认权；记录误分案例用于迭代 |
| **评估过载** | 五模块都可能推评估/录入，教师被淹没 | "月度轻量 + 按需录入"节奏控制；单模块首屏 ≤10 分钟 |
| **方案太泛** | 给出的方案"道理都对 but 落不了地" | 每个方案必须附带 ≥1 个"明天就能用"的可执行工具；有用性反馈闭环迭代 |
| **效果不确定** | 轻量工具短期效果不显著 | 指标诚实化（3 个月周期）；不做夸大承诺；设置合理预期 |
| **隐私/合规** | 学生(未成年人)/家长数据高度敏感 | 教师私有 + 脱敏 + 分级权限 + 彻底移除管理层视角；定期合规审计 |
| **过度依赖** | 教师把平台当成唯一出口，错过真正的专业需求 | 安全熔断 + 明确 Non-goals（不替代专业介入） |
| **红线漏报** | 自动检测遗漏危机信号 | 关键词库 + 语义模型 + 人工复核兜底；漏报率为核心健康指标 |
| **数据孤岛** | 五模块数据互不通，教师重复录入 | 统一信息管理中心 + 学生/家长 ID 跨模块关联 |
