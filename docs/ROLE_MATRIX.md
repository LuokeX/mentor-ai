# 角色权限矩阵

| 能力 | 教师 | 心理专员 | 学校管理员 | 平台管理员 |
|---|---:|---:|---:|---:|
| AI 与四模块 | 自己 | 否 | 否 | 否 |
| 自己的档案/方案 | 读写 | 否 | 事由授权后只读 | 学校批准后只读 |
| 其他教师业务数据 | 否 | 否 | 本校、目标级、15 分钟 | 指定目标、最长 30 分钟 |
| 危机转介 | 发起 | 仅分配工单、确认/线下状态 | 状态与受控关联记录 | 默认不可见 |
| 教师/心理账号 | 否 | 否 | 本校创建、启停、重置 | 否 |
| 学校与学校管理员 | 否 | 否 | 否 | 创建、启停 |
| 内容包 | 否 | 否 | 否 | 草稿、发布、回滚、停用 |
| 批量导出管理数据 | 否 | 否 | 禁止 | 禁止 |

## 敏感访问不变量

1. 学校管理员必须填写至少 10 个字符的事由，授权只匹配管理员、学校、目标类型和目标 UUID，有效 15 分钟。
2. 平台管理员只能发起申请；对应学校管理员批准后生成最长 30 分钟授权。授权不能覆盖整校。
3. 敏感详情接口必须携带 `X-Admin-Access-Grant`，并再次校验操作者、目标和到期时间。
4. 管理员没有业务修改、删除或批量导出接口；详情响应禁止缓存，页面带管理员/时间/授权号水印。
5. 打印时隐藏敏感正文，并把 `print_attempt` 写入独立访问事件表。
6. 教师个人接口按 `owner_user_id` 查询；外键关联对象也必须属于当前教师和学校。

上线签字时需附上校方确认的账号开通告知和隐私说明，明确学校管理员的受控只读范围。
