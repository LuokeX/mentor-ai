# 角色权限矩阵

| 能力 | 教师 | 心理专员 | 学校管理员 | 平台管理员 |
|---|---:|---:|---:|---:|
| AI 分诊与五模块 | 自己 | 否 | 否 | 否 |
| 自己的档案/方案 | 读写 | 否 | 事由授权后只读 | 学校批准后只读 |
| 其他教师业务过程记录 | 否 | 否 | 本校、目标级、15 分钟只读 | 指定目标、最长 30 分钟只读 |
| 部门/学生/家长/班级基础资料 | 自己负责范围读写 | 否 | 本校创建、编辑、归档、恢复、流转 | 否 |
| 危机转介 | 发起 | 仅分配工单、确认/线下状态 | 状态与受控关联记录 | 默认不可见 |
| 教师/心理账号 | 否 | 否 | 本校创建、启停、重置 | 全校查看、创建、编辑、启停、重新邀请 |
| 学校与学校管理员 | 否 | 否 | 否 | 创建、编辑、启停、邀请学校管理员 |
| 三库资源/内容包 | 否 | 否 | 否 | 草稿、发布、回滚、停用 |
| 批量导出管理数据 | 否 | 否 | 禁止 | 禁止 |

## 敏感访问不变量

1. 学校管理员必须填写至少 10 个字符的事由，授权只匹配管理员、学校、目标类型和目标 UUID，有效 15 分钟。
2. 平台管理员直接管理全校教师/心理账号（查看、创建、编辑、启停、重新邀请），操作同样写入审计日志；不得通过账号管理入口修改评估、聊天、危机、方案等业务过程正文。
3. 敏感详情接口必须携带 `X-Admin-Access-Grant`，并再次校验操作者、目标和到期时间。
4. 管理员可以维护基础资料，包含校内账号、教师、部门、班级、学生和家长关系；不得直接修改评估、聊天、危机、方案等业务过程正文；详情响应禁止缓存，页面带管理员/时间/授权号水印。
5. 打印时隐藏敏感正文，并把 `print_attempt` 写入独立访问事件表。
6. 教师个人接口按 `owner_user_id` 查询；外键关联对象也必须属于当前教师和学校。
7. 部门、班级、学生、家长删除统一采用 `archived` 等状态流转，不做硬删除；跨负责教师流转必须记录 `record_assignments` 和审计日志。

上线签字时需附上校方确认的账号开通告知和隐私说明，明确学校管理员的受控只读范围。
