# 方案结构规范

方案不是独立业务库。系统根据“量表评估结果 + 归因库输出 + 工具库匹配 + 方案输出模板”确定性生成方案草稿，老师确认后进入跟踪复盘。业务侧统一在 `business-libraries/templates/三库填写模板_v3.xlsx` 的 ⑩ 方案输出模板维护摘要、结论、目标、行动、注意事项和复盘提示。

## 固定结构

| 字段 | 来源 |
| --- | --- |
| 问题摘要 | ⑩ 方案输出模板或报告生成器兜底 |
| 评估结论 | 量表分数、⑤e 等级和 ⑩ 方案输出模板 |
| 主归因/次归因 | 归因库 |
| 支持目标 | 归因等级与模块规则 |
| 行动项 | 归因库默认动作 + 工具转化动作 |
| 推荐工具 | 工具库匹配结果 |
| 注意事项/禁忌 | 工具库 `prohibitions` 与安全规则 |
| 下次复盘时间 | 默认 7 天，可由工具建议周期覆盖 |

## 业务侧需补齐

- 每个模块行动项数量范围，例如 2-5 条。
- 工具组合规则：同等级最多几个工具，哪些工具不可同时出现。
- 复盘周期规则：默认周期、短周期、高风险周期。
- 人工协同条件：哪些等级必须提示年级组、德育、心理专员或学校管理员协同。
- AI 边界：AI 只能做复盘追问和表达润色，不得改变等级、归因、工具、禁忌和风险判断。
