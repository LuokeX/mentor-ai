## 导入命令

```bash
# 试运行（不写库）
pnpm import:business-data --dry-run

# 全部导入并发布
pnpm import:business-data --publish

# 单模块导入
pnpm import:business-data --module=class_system --publish

# 仅导入工具库
pnpm import:business-data --type=tool --publish
```

## 系统集成状态

导入后的数据通过以下路径参与系统运行：

| 数据类型 | 首页 AI 分诊 | 模块主流程 | 教师端浏览 |
|---------|:------:|:-------:|:--------:|
| assessment (量表) | 不直接使用 | 通过 `resolveAssessmentDefinition` 加载 | `GET /assessments/[module]/instruments` 列表 |
| attribution (归因) | 不直接使用 | 通过 `resolveAttributionConfig` + `executeRules` 输出等级和归因 | 随报告展示 |
| tool (工具/处方) | 不直接使用 | 通过 `resolveToolsForPlan` 动态匹配注入 | `listPublishedModuleTools` 返回列表 |

原始资料中的术语、专业知识、SOP、话术和案例不再作为独立运行时库导入；业务侧需要将其中可执行内容整理进量表库、归因库或工具库。
